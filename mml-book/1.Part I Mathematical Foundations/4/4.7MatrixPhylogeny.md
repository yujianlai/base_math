## 4.7.1 谱系树（图 4.13）

> **备注**。"phylogenetic（系统发育/谱系）"一词源自希腊语中表示"部族"和"来源"的词汇——本节给矩阵们画一棵"亲缘树"。♦

从最大的家族开始逐级细分（图 4.13，黑色箭头 = "是……的子集"）：

**第 0 层：所有实矩阵 $\boldsymbol A \in \mathbb{R}^{n \times m}$**

- **非方阵**（$n \neq m$）：没有行列式、没有特征值，但**SVD 总是存在**（4.5 节）——这是 SVD 被称为"基本定理"的原因之一。

**第 1 层：方阵 $\boldsymbol A \in \mathbb{R}^{n \times n}$**

- **行列式**可用：$\det(\boldsymbol A) \neq 0 \iff$ **正则/可逆**（定理 4.1、4.3）。
- 若拥有 $n$ 个线性无关的特征向量（**非亏损**，定理 4.12），则**特征分解存在**（定理 4.20）。重特征值可能造成亏损；亏损矩阵无法对角化。
- **注意**："非奇异"与"非亏损"是**两个独立的概念**！经典反例：旋转矩阵可逆（$\det = 1$），但特征值是复数，在实数范围内不可对角化（4.2 节图 4.4 的 $\boldsymbol A_3$）。

**第 2 层：非亏损方阵中**

- **正规矩阵（normal）**：满足 $\boldsymbol A^\top \boldsymbol A = \boldsymbol A \boldsymbol A^\top$（左乘自己的转置可交换）。
- **正交矩阵（orthogonal）**：更强，$\boldsymbol A^\top \boldsymbol A = \boldsymbol A \boldsymbol A^\top = \boldsymbol I$（定义 3.8），是可逆矩阵的子集，满足 $\boldsymbol A^\top = \boldsymbol A^{-1}$（旋转/翻转）。

**第 3 层：正规矩阵的子家族——对称矩阵 $\boldsymbol S = \boldsymbol S^\top$**

- 只有**实特征值**（谱定理，定理 4.15）；
- 子集 **正定矩阵**：$\boldsymbol x^\top \boldsymbol P \boldsymbol x > 0$（$\boldsymbol x \neq \boldsymbol 0$）——特征值全正、必可逆，**唯一 Cholesky 分解**（定理 4.18）；
- 子集 **对角矩阵** $\boldsymbol D$：在乘法、加法下封闭（全体可逆对角矩阵构成群；含零对角元的不是）。

**第 4 层：特殊的对角矩阵——单位矩阵 $\boldsymbol I$**

## 4.7.2 矩阵类 × 可用运算对照表

| 矩阵类 | 行列式 | 特征分解 | Cholesky | SVD |
| --- | --- | --- | --- | --- |
| 任意 $m \times n$ | — | — | — | ✓ 总存在 |
| 可逆方阵 | ✓ $\neq 0$ | 未必（可能亏损） | — | ✓ |
| 非亏损方阵 | ✓ | ✓ $\boldsymbol P\boldsymbol D\boldsymbol P^{-1}$ | — | ✓ |
| 对称矩阵 | ✓ | ✓ $\boldsymbol P\boldsymbol D\boldsymbol P^\top$（$\boldsymbol P$ 正交） | 若正定则 ✓ | ✓（= 特征分解） |
| 对称正定 | ✓ $>0$ | ✓ 特征值全正 | ✓ **唯一** | ✓ |
| 正交矩阵 | ✓ $=\pm 1$ | 未必实对角化 | — | ✓（奇异值全 1） |
| 对角矩阵 | ✓ 对角元连乘 | ✓（自身） | 若元全正则 ✓ | ✓ |

**记忆口诀**：条件越强的矩阵家族，配的工具越锋利；SVD 是最不挑食的——**任何矩阵都有**。

## 本节小结

谱系树回答两个问题：**这个矩阵属于哪一类？**（决定它有哪些性质）和**我能对它做什么运算？**（分解是否存在、是否唯一）。遇到实际矩阵时，先判断它落在树的哪个位置，再选择相应的工具。

**与其他章节的关系**：这张分类表是全书矩阵工具的索引——协方差矩阵（SPD）→ Cholesky + 特征分解；数据表（任意矩阵）→ SVD；正交矩阵 → 旋转与保距变换。
