# 6.5 高斯分布（Gaussian Distribution）

## 本节导学

**学习目标**

1. 记住单变量与多元高斯分布的密度公式，说清每个符号的含义；
2. 掌握两大封闭性质：边缘分布/条件分布仍是高斯；线性/仿射变换仍是高斯；
3. 会套用条件高斯公式（(6.66)(6.67)）做数值计算；
4. 知道高斯乘积公式（贝叶斯推断的核心计算）与混合高斯的均值方差公式；
5. 会用 Cholesky 分解从 $\mathcal N(\boldsymbol 0, \boldsymbol I)$ 采样任意高斯。

**预备知识**：6.4 节（均值、协方差）、4.3 节（Cholesky）、3.2.3 节（正定矩阵）、2.7.3 节（伪逆）。

**符号速查表**：

| 符号 | 含义 |
| --- | --- |
| $\mathcal N(\mu, \sigma^2)$ / $\mathcal N(\boldsymbol\mu, \boldsymbol\Sigma)$ | 单变量 / 多元高斯分布 |
| $\|\boldsymbol\Sigma\|$ | 协方差矩阵的行列式（注意与范数区分，靠上下文） |
| $\boldsymbol\Sigma^{-1}$ | 精度矩阵（precision matrix） |
| $\mathcal N(\boldsymbol x \mid \boldsymbol\mu, \boldsymbol\Sigma)$ | 作为 $\boldsymbol x$ 的函数看待密度（竖线读法） |
| 标准正态 | $\mathcal N(\boldsymbol 0, \boldsymbol I)$ |

## 6.5.1 定义与基本性质

**高斯分布（Gaussian）**= **正态分布（normal）**，是连续随机变量中研究得最透彻的分布。它自然出现于"独立同分布随机变量之和"——**中心极限定理**（Grinstead and Snell, 1997）。重要性来自**计算上的极大便利**：边缘、条件、线性变换全有闭式；因此它定义了线性回归的似然与先验（第 9 章）、高斯混合模型（第 11 章），还支撑高斯过程、卡尔曼滤波、假设检验等。

**单变量**密度：

$$
p(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right) \tag{6.62}
$$

**多元**密度（$D$ 维，完全由均值向量 $\boldsymbol\mu$ 与协方差矩阵 $\boldsymbol\Sigma$ 决定）：

$$
p(\boldsymbol x \mid \boldsymbol \mu, \boldsymbol \Sigma) = (2\pi)^{-\frac{D}{2}} |\boldsymbol \Sigma|^{-\frac{1}{2}} \exp\left( -\frac{1}{2}(\boldsymbol x - \boldsymbol \mu)^\top \boldsymbol \Sigma^{-1} (\boldsymbol x - \boldsymbol \mu) \right) \tag{6.63}
$$

记作 $p(\boldsymbol x) = \mathcal N(\boldsymbol x \mid \boldsymbol \mu, \boldsymbol \Sigma)$ 或 $\boldsymbol X \sim \mathcal N(\boldsymbol \mu, \boldsymbol \Sigma)$。$\boldsymbol\mu = \boldsymbol 0$、$\boldsymbol\Sigma = \boldsymbol I$ 的特例叫**标准正态分布**。图 6.7 画二元高斯的曲面与等高线；图 6.8 叠加了 100 个样本。

**分项解读 (6.63)**（零基础友好）：
- $(2\pi)^{-D/2}|\boldsymbol\Sigma|^{-1/2}$：归一化常数，保证积分为 1；
- $\boldsymbol\Sigma^{-1}$（**精度矩阵**）：协方差越大 → 精度越小 → 密度越"平"；
- 二次型 $(\boldsymbol x - \boldsymbol\mu)^\top\boldsymbol\Sigma^{-1}(\boldsymbol x - \boldsymbol\mu)$：到均值的"马氏距离平方"——沿方差小的方向衰减快。

## 6.5.2 边缘与条件：高斯家族的封闭性

把联合高斯按变量分块（$\boldsymbol\Sigma_{yx} = \boldsymbol\Sigma_{xy}^\top$，互协方差）：

$$
p(\boldsymbol x, \boldsymbol y) = \mathcal N\left( \begin{bmatrix} \boldsymbol \mu_x \\ \boldsymbol \mu_y \end{bmatrix}, \begin{bmatrix} \boldsymbol \Sigma_{xx} & \boldsymbol \Sigma_{xy} \\ \boldsymbol \Sigma_{yx} & \boldsymbol \Sigma_{yy} \end{bmatrix} \right) \tag{6.64}
$$

**条件分布** $p(\boldsymbol x \mid \boldsymbol y)$ **仍是高斯**（推导见 Bishop 2006 第 2.3 节）：

$$
\boldsymbol \mu_{x \mid y} = \boldsymbol \mu_x + \boldsymbol \Sigma_{xy}\boldsymbol \Sigma_{yy}^{-1}(\boldsymbol y - \boldsymbol \mu_y), \qquad
\boldsymbol \Sigma_{x \mid y} = \boldsymbol \Sigma_{xx} - \boldsymbol \Sigma_{xy}\boldsymbol \Sigma_{yy}^{-1}\boldsymbol \Sigma_{yx} \tag{6.65–6.67}
$$

（注意：$\boldsymbol y$ 是**观测值**，不再是随机变量。）**边缘分布** $p(\boldsymbol x) = \mathcal N(\boldsymbol\mu_x, \boldsymbol\Sigma_{xx})$——"直接读分块矩阵的对角块"（(6.68)，图 6.9）。

> **例 6.6（条件高斯数值计算）**。

$$
p(x_1, x_2) = \mathcal N\left( \begin{bmatrix} 0 \\ 2 \end{bmatrix}, \begin{bmatrix} 0.3 & -1 \\ -1 & 5 \end{bmatrix} \right) \tag{6.69}
$$

分块读出：$\mu_{x_1} = 0$，$\Sigma_{x_1 x_1} = 0.3$，$\Sigma_{x_1 x_2} = -1$，$\Sigma_{x_2 x_2} = 5$。

**第 1 步**：$\Sigma_{yy}^{-1} = 5^{-1} = 0.2$。

**第 2 步**（条件均值，$\boldsymbol y = x_2 = -1$）：

$$
\mu_{x_1 \mid x_2 = -1} = 0 + (-1)(0.2)(-1 - 2) = 0.6 \tag{6.70}
$$

**第 3 步**（条件方差）：

$$
\sigma^2_{x_1 \mid x_2 = -1} = 0.3 - (-1)(0.2)(-1) = 0.3 - 0.2 = 0.1 \tag{6.71}
$$

即 $p(x_1 \mid x_2 = -1) = \mathcal N(0.6, 0.1)$（(6.72)）。**边缘分布**直接读块：$p(x_1) = \mathcal N(0, 0.3)$（(6.73)）。（直观：观测 $x_2$ 后，对 $x_1$ 的估计从"均值 0、方差 0.3"更新为"均值 0.6、方差 0.1"——**信息增加了，不确定性下降了**。）

**应用无处不在**：卡尔曼滤波（每步都是高斯条件化）、高斯过程（对观测数据条件化函数分布）、概率 PCA（第 10.7 节）。

## 6.5.3 高斯的乘积（贝叶斯推断的核心）

两个高斯密度之积**仍是高斯**（乘一个尺度因子）：

$$
\mathcal N(\boldsymbol x \mid \boldsymbol a, \boldsymbol A)\,\mathcal N(\boldsymbol x \mid \boldsymbol b, \boldsymbol B) = c\,\mathcal N(\boldsymbol x \mid \boldsymbol c, \boldsymbol C)
$$

$$
\boldsymbol C = (\boldsymbol A^{-1} + \boldsymbol B^{-1})^{-1}, \qquad \boldsymbol c = \boldsymbol C(\boldsymbol A^{-1}\boldsymbol a + \boldsymbol B^{-1}\boldsymbol b), \qquad c = (2\pi)^{-\frac{D}{2}}|\boldsymbol A + \boldsymbol B|^{-\frac{1}{2}} \exp\big(-\tfrac{1}{2}(\boldsymbol a - \boldsymbol b)^\top(\boldsymbol A + \boldsymbol B)^{-1}(\boldsymbol a - \boldsymbol b)\big) \tag{6.74–6.76}
$$

（推导：配方法，练习 6.10。）**精度相加、精度加权平均**——第 9 章贝叶斯线性回归的"后验 = 似然 × 先验"正是这个公式的直接应用。尺度因子本身也可写成"膨胀协方差"的高斯：$c = \mathcal N(\boldsymbol a \mid \boldsymbol b, \boldsymbol A + \boldsymbol B)$（(6.77)——这里 $\boldsymbol a, \boldsymbol b$ 不是随机变量，只是把密度的函数形式借来用）。

## 6.5.4 和、线性变换与混合

**独立高斯之和**仍是高斯：$\boldsymbol x + \boldsymbol y \sim \mathcal N(\boldsymbol\mu_x + \boldsymbol\mu_y,\ \boldsymbol\Sigma_x + \boldsymbol\Sigma_y)$（(6.78)；均值方差直接由 (6.46)(6.48) + 独立性得出）。加权版本：$a\boldsymbol x + b\boldsymbol y \sim \mathcal N(a\boldsymbol\mu_x + b\boldsymbol\mu_y,\ a^2\boldsymbol\Sigma_x + b^2\boldsymbol\Sigma_y)$（(6.79)）。

**任意仿射变换封闭**：$\boldsymbol X \sim \mathcal N(\boldsymbol\mu, \boldsymbol\Sigma)$，$\boldsymbol y = \boldsymbol A\boldsymbol x$ ⟹

$$
p(\boldsymbol y) = \mathcal N(\boldsymbol A\boldsymbol\mu,\ \boldsymbol A\boldsymbol\Sigma\boldsymbol A^\top) \tag{6.86–6.88}
$$

（均值、协方差由 (6.50)(6.51) 直接算出——分布形式仍是高斯，这是高斯的特权。）**逆问题**（已知 $\boldsymbol y \sim \mathcal N(\boldsymbol{Ax}, \boldsymbol\Sigma)$ 求 $\boldsymbol x$）：$\boldsymbol A$ 列满秩但可能不可逆时，用伪逆手法 (3.57)——两边左乘 $\boldsymbol A^\top$ 再对 $\boldsymbol A^\top\boldsymbol A$ 求逆：

$$
\boldsymbol x = (\boldsymbol A^\top \boldsymbol A)^{-1}\boldsymbol A^\top \boldsymbol y \implies p(\boldsymbol x) = \mathcal N\big((\boldsymbol A^\top\boldsymbol A)^{-1}\boldsymbol A^\top \boldsymbol y,\ (\boldsymbol A^\top\boldsymbol A)^{-1}\boldsymbol A^\top \boldsymbol \Sigma \boldsymbol A (\boldsymbol A^\top \boldsymbol A)^{-1}\big) \tag{6.90, 6.91}
$$

**混合高斯 ≠ 高斯的和**。$p(x) = \alpha p_1(x) + (1-\alpha)p_2(x)$（密度的**加权和**）一般**不是**高斯（例 6.4 的双峰分布）：

**定理 6.12**（混合高斯的均值与方差，(6.80)–(6.82)）：

$$
\mathbb{E}[x] = \alpha\mu_1 + (1-\alpha)\mu_2
$$

$$
\mathbb{V}[x] = \underbrace{\alpha\sigma_1^2 + (1-\alpha)\sigma_2^2}_{\text{各分量方差的加权}} + \underbrace{\alpha\mu_1^2 + (1-\alpha)\mu_2^2 - [\alpha\mu_1 + (1-\alpha)\mu_2]^2}_{\text{分量均值之间的散布}}
$$

**证明**（完整展示）：均值——把 $p$ 代入期望定义、拆积分、各分量归一即得 (6.83)。方差——用原始得分公式 (6.44)，先算

$$
\mathbb{E}[x^2] = \alpha(\mu_1^2 + \sigma_1^2) + (1-\alpha)(\mu_2^2 + \sigma_2^2) \tag{6.84}
$$

（用了 $\sigma^2 = \mathbb{E}[x^2] - \mu^2$ 反解 $\mathbb{E}[x^2] = \sigma^2 + \mu^2$），再减去均值的平方，整理即得 (6.85c)。$\blacksquare$

**解读**：方差 = "分量内部的平均方差" + "分量均值之间的方差"——这正是**全方差公式（law of total variance）** $\mathbb{V}_X[x] = \mathbb{E}_Y[\mathbb{V}_X[x\mid y]] + \mathbb{V}_Y[\mathbb{E}_X[x\mid y]]$ 的实例（把分量指示看作 $Y$）。第 11 章高斯混合模型反复使用此公式。

## 6.5.5 从多元高斯中采样

三阶段流程：
1. 伪随机数源 → $[0,1]$ 均匀样本；
2. 非线性变换（如 Box-Müller）→ 单变量高斯样本；
3. 组装成 $\mathcal N(\boldsymbol 0, \boldsymbol I)$ 的向量样本。

**从标准到一般**：利用仿射封闭性——若 $\boldsymbol A\boldsymbol A^\top = \boldsymbol\Sigma$，则

$$
\boldsymbol z \sim \mathcal N(\boldsymbol 0, \boldsymbol I) \implies \boldsymbol y = \boldsymbol A\boldsymbol z + \boldsymbol \mu \sim \mathcal N(\boldsymbol \mu, \boldsymbol \Sigma)
$$

取 $\boldsymbol A$ 为 $\boldsymbol\Sigma$ 的**乔莱斯基因子**（4.3 节，$\boldsymbol\Sigma = \boldsymbol L\boldsymbol L^\top$；协方差矩阵总是对称正定的，满足分解条件）——三角结构让运算高效。验证：$\mathbb V[\boldsymbol y] = \boldsymbol A\,\mathbb V[\boldsymbol z]\,\boldsymbol A^\top = \boldsymbol A\boldsymbol A^\top = \boldsymbol\Sigma$ ✓。
