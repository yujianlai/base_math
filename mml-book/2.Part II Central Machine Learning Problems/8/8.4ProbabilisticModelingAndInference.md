# 8.4 概率建模与推断（Probabilistic Modeling and Inference）

## 本节导学

**学习目标**

1. 理解**概率模型由其所有随机变量的联合分布唯一定义**，以及联合分布如何统摄先验、似然、边缘似然、后验；
2. 掌握**贝叶斯推断**的核心：求后验分布（计算问题从"优化"变为"积分"），以及边缘化预测 (8.23) 的含义；
3. 知道近似推断工具箱：MCMC、拉普拉斯近似、变分推断、期望传播；
4. 掌握**隐变量模型**的两步学习流程：先边缘化隐变量得似然 (8.25)，再做参数估计/贝叶斯推断；
5. 分清两类"隐藏量"：模型参数 $\boldsymbol\theta$ 与隐变量 $\boldsymbol z$。

**预备知识**：6.3 节（贝叶斯定理）、6.6.1 节（共轭先验）、8.3 节（参数估计）。

**符号速查表**：

| 符号 | 含义 |
| --- | --- |
| $p(\boldsymbol x, \boldsymbol\theta)$ | 观测与参数的联合分布（概率模型的核心） |
| $p(\boldsymbol\theta \mid \mathcal X)$ | 参数后验 (8.22) |
| $p(\boldsymbol x) = \int p(\boldsymbol x \mid \boldsymbol\theta)p(\boldsymbol\theta)\,\mathrm d\boldsymbol\theta$ | 边缘似然 / 证据 |
| $p(\boldsymbol x) = \mathbb E_{\boldsymbol\theta}[p(\boldsymbol x \mid \boldsymbol\theta)]$ | 贝叶斯预测分布 (8.23) |
| $\boldsymbol z$ | 隐变量（不显式参数化模型，但参与生成数据） |
| EM | 期望最大化（隐变量模型的标准学习算法） |

## 8.4.1 概率模型

机器学习常要解释数据、预测未来、辅助决策——为此构建描述**生成过程（generative process）**的模型。掷硬币的两步示例：定义参数 $\mu$（正面的概率）→ 从 $\text{Ber}(\mu)$ 采样结果 $x$。$\mu$ 未知且不可直接观测，需要机制从观测结果中学习它——这就是概率建模。

**概率模型的定义**：把实验中不确定的方面表示为概率分布；**由所有随机变量的联合分布唯一定义**。联合分布 $p(\boldsymbol x, \boldsymbol\theta)$ 处于核心地位，它囊括了：

1. **先验与似然**（乘法法则 $p(\boldsymbol x, \boldsymbol\theta) = p(\boldsymbol x \mid \boldsymbol\theta)p(\boldsymbol\theta)$，6.3 节）；
2. **边缘似然** $p(\boldsymbol x)$（对参数积分；8.6 节模型选择的主角）；
3. **后验** $p(\boldsymbol\theta \mid \boldsymbol x)$（联合除以边缘似然）。

**唯有联合分布具备这种完备性**——这就是为什么"概率模型 = 联合分布"。

## 8.4.2 贝叶斯推断

**任务**：给定观测 $\boldsymbol x$，揭示隐藏变量 $\boldsymbol\theta$。8.3 节的 MLE/MAP 给出**单一最佳值**（优化问题），然后预测用 $p(\boldsymbol x \mid \boldsymbol\theta^*)$。

**为什么要后验而不仅是点估计**（6.3 节备注的再现）：决策系统的目标函数常与似然不同（平方误差、误分类代价），只用 $\boldsymbol\theta^*$ 会丢失参数不确定性信息，可能致命。**贝叶斯推断的核心 = 寻找完整后验分布**（Gelman et al., 2004）：

$$
p(\boldsymbol\theta \mid \mathcal X) = \frac{p(\mathcal X \mid \boldsymbol\theta)\, p(\boldsymbol\theta)}{p(\mathcal X)}, \qquad p(\mathcal X) = \int p(\mathcal X \mid \boldsymbol\theta)\, p(\boldsymbol\theta)\,\mathrm d\boldsymbol\theta \tag{8.22}
$$

——本质是用贝叶斯定理**反转**参数与数据的关系。

**贝叶斯预测 = 边缘化**。拥有后验后，对新数据的预测把所有合理参数值**加权平均**（权重 = 参数分布）：

$$
p(\boldsymbol x) = \int p(\boldsymbol x \mid \boldsymbol\theta)\, p(\boldsymbol\theta)\,\mathrm d\boldsymbol\theta = \mathbb E_{\boldsymbol\theta}[p(\boldsymbol x \mid \boldsymbol\theta)] \tag{8.23}
$$

——$\boldsymbol\theta$ 被积分滤除，预测不再依赖任何单个参数值。

**点估计 vs 贝叶斯推断的对照表**：

| | 参数估计（MLE/MAP） | 贝叶斯推断 |
| --- | --- | --- |
| 输出 | 点估计 $\boldsymbol\theta^*$ | 后验分布 |
| 核心计算 | **优化** | **积分** |
| 预测 | 代入 $\boldsymbol\theta^*$，直接 | 再解一个积分 (8.23) |
| 先验融合 | MAP 可加入 | 规范地融合先验、辅助信息、结构知识 |
| 不确定性 | 丢失 | 传播到预测，利于风险决策与主动探索（Deisenroth et al., 2015; Kamthe and Deisenroth, 2018） |

**实际挑战**：非共轭先验下 (8.22)(8.23) 的积分**解析不可积**。近似工具箱：

- **随机近似**：马尔可夫链蒙特卡洛（MCMC）（Gilks et al., 1996）；
- **确定性近似**：拉普拉斯近似（Bishop, 2006; Barber, 2012; Murphy, 2012）、变分推断（Jordan et al., 1999; Blei et al., 2017）、期望传播（Minka, 2001a）。

**成功应用**：大规模主题建模（Hoffman et al., 2013）、点击率预测（Graepel et al., 2010）、数据高效强化学习（Deisenroth et al., 2015）、在线排名（Herbrich et al., 2007）、大规模推荐系统、贝叶斯优化（Brochu et al., 2009; Snoek et al., 2012; Shahriari et al., 2016）。

> **备注（变量 vs 参数）**：界限相对随意——通常参数是"被估计的"，变量是"被边缘化的"；原则上任何参数都可以赋先验再积分掉，从而"变成"随机变量。♦

## 8.4.3 隐变量模型

**隐变量（latent variables）$\boldsymbol z$**：除参数 $\boldsymbol\theta$ 之外、不显式参数化模型、但参与数据生成的隐藏量。好处：

- **可解释性**：描述生成过程（"哪个主题生成了这段文字"）；
- **结构简化**：更简单却更丰富的架构，参数更少（Paquet, 2008; Murphy, 2012）；
- 学习算法：**EM（期望最大化）**（Dempster et al., 1977; Bishop, 2006）。

典型例子：PCA（第 10 章）、高斯混合模型（第 11 章）、隐马尔可夫模型/动力系统（Maybeck, 1979; Ghahramani and Roweis, 1999）、元学习（Hausman et al., 2018）。

**生成视角**。条件分布

$$
p(\boldsymbol x \mid \boldsymbol\theta, \boldsymbol z) \tag{8.24}
$$

——给定参数和隐变量即可生成数据；$\boldsymbol z$ 上有先验 $p(\boldsymbol z)$。

**两步学习流程**（与 8.3/8.4.2 完全同构）：

**第 1 步：边缘化隐变量，得到似然**。

$$
p(\boldsymbol x \mid \boldsymbol\theta) = \int p(\boldsymbol x \mid \boldsymbol\theta, \boldsymbol z)\, p(\boldsymbol z)\,\mathrm d\boldsymbol z \tag{8.25}
$$

**似然绝不能依赖隐变量**——它只是数据与参数的函数（(8.25) 右端已不见 $\boldsymbol z$）。

**第 2 步**：用该似然做 MLE（8.3.1）、MAP（8.3.2 加 $p(\boldsymbol\theta)$ 先验）或贝叶斯推断：

$$
p(\boldsymbol\theta \mid \mathcal X) = \frac{p(\mathcal X \mid \boldsymbol\theta)\, p(\boldsymbol\theta)}{p(\mathcal X)} \tag{8.26}
$$

**挑战**：(8.25) 的边缘化除非共轭，否则解析不可积——需要近似方法（Bishop, 2006; Paquet, 2008; Murphy, 2012; Moustaki et al., 2015）。

**隐变量自己的后验**。也可以对 $\boldsymbol z$ 做贝叶斯推断：

$$
p(\boldsymbol z \mid \mathcal X) = \frac{p(\mathcal X \mid \boldsymbol z)\, p(\boldsymbol z)}{p(\mathcal X)}, \qquad p(\mathcal X \mid \boldsymbol z) = \int p(\mathcal X \mid \boldsymbol z, \boldsymbol\theta)\, p(\boldsymbol\theta)\,\mathrm d\boldsymbol\theta \tag{8.27}
$$

——需要对参数再积分。**同时边缘化 $\boldsymbol z$ 和 $\boldsymbol\theta$ 一般不可行**（双重积分）。更可行的是**以参数为条件**的隐变量后验：

$$
p(\boldsymbol z \mid \mathcal X, \boldsymbol\theta) = \frac{p(\mathcal X \mid \boldsymbol z, \boldsymbol\theta)\, p(\boldsymbol z)}{p(\mathcal X \mid \boldsymbol\theta)} \tag{8.28}
$$

第 10、11 章将分别为 PCA 和高斯混合模型推导似然，并计算条件后验 (8.28)。

> **备注（术语）**：后续章节不再严格区分 $\boldsymbol z$ 与不确定的 $\boldsymbol\theta$——都不可观测，统称"潜变量"；但 10、11 章两者同时存在时会格外注意区分。♦

## 8.4.4 延伸阅读

- 概率模型教材：Bishop (2006)、Barber (2012)、Murphy (2012)；综述：Ghahramani (2015)。
- 一般情形下积分无解析解，用采样（MCMC, Gilks et al., 1996; Brooks et al., 2011）与变分推断（Jordan et al., 1999; Blei et al., 2017)；隐变量模型的贝叶斯推断综述：Moustaki et al. (2015)、Paquet (2008)。
- **概率编程（probabilistic programming）**：把程序中的变量直接当作概率分布的随机变量，编译器自动执行贝叶斯推断——正在快速发展的领域。

## 本节小结

| 要点 | 内容 |
| --- | --- |
| 概率模型 | 联合分布 $p(\boldsymbol x, \boldsymbol\theta)$ 唯一确定；统摄先验/似然/证据/后验 |
| 贝叶斯推断 | 后验 = 核心目标；预测 = 对参数取期望 (8.23)；计算难点是积分 |
| 隐变量模型 | 先边缘化 $\boldsymbol z$ 得似然 (8.25)，再走标准流程；EM 是学习算法 |
| 参数 vs 隐变量 | $\boldsymbol\theta$ 参数化模型；$\boldsymbol z$ 参与生成但不参数化；条件后验 (8.28) 更可行 |

**与其他章节的关系**：第 9 章 = 无隐变量的贝叶斯推断全解（共轭高斯，闭式）；第 10、11 章 = 隐变量模型的两大实例（PCA、GMM），EM 算法登场；8.5 节的图语言将让这些模型的结构一目了然。
