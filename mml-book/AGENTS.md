# mml-book 章节优化编写规范

本目录内容来源于 `../../mml-book-chinese-main`（Mathematics for Machine Learning 中文版）的 Part I 与 Part II，目标读者是**零基础读者**。每章在拷贝原文的基础上做深度优化，使读者只读本文档即可透彻理解该章节。

## 目录结构

镜像原仓库结构，文件名与原文件保持一致：

```
mml-book/
├── 1.Part I Mathematical Foundations/
│   ├── 2/2.6BasisAndRank.md   ← 参考样章（以此为准）
│   └── ...
└── 2.Part II Central Machine Learning Problems/
    └── ...
```

## 每章必须包含的模块（参考样章 2.6BasisAndRank.md）

1. **本章导学**：学习目标列表（3–5 条，可检验）、预备知识（明确指出依赖哪些前序章节的概念）、**符号速查表**（本章所有数学符号：读法 + 含义，表格形式）。
2. **直观引入**：先用几何直觉或简单例子解释"本节要解决什么问题"，再给正式定义。
3. **正文**：
   - 每个正式定义后必须有"逐句解读 / 通俗地说"；
   - 每个重要定理/性质说明"为什么"（给出证明或直觉解释，不引用"显然"）；
   - 原文中被跳过的计算（如 `$\leadsto \cdots \leadsto$`）必须**逐步补全**：写清每一步做了什么行变换、算出了什么；
   - 原文直接断言的结论（如"向量 X 无法由集合 A 线性表出"）必须**亲手验证**并展示过程；
   - 新增帮助理解的例子时，用带撇的编号（如"例 2.15'"）以区分原书编号；
   - 保持原书的定义编号、公式编号（如 定义 2.13、式 (2.77)）不变，方便与原书对照。
4. **本节小结**：核心概念表 + 核心技能一句话 + 与其他章节的关系。
5. **习题单独成文件**：习题**不跟在讲解章节后面**，统一放在该章目录下的 `Exercises.md`（每章一个文件，仿照原仓库结构），从原 `Exercises.md` **原样拷贝**与本节相关的习题，不改题目；文件开头用引用块说明各练习对应的知识点小节，后续小节完成时持续补充进同一文件。

## 写作要求

- 语言面向零基础读者：概念首次出现时解释清楚，避免"易证""不难看出"等表述。
- 数学推导展示计算方法和全过程，关键步骤标注（✓ 验证、$\blacksquare$ 证明结束）。
- 公式风格沿用原文（`$...$` / `$$...$$`、bmatrix、`\operatorname` 等）；`\tag{...}` 只能用于块级公式（独立成行的公式）。注意：**表格单元格内不要出现 `\tag`、反引号代码、`$$` 字面量或裸露的反斜杠**，一律用纯文本描述（如"式 (2.77) 尾部的编号"、"独立成行的公式"），否则部分渲染器会显示异常。
- 章节标题层级：章标题用 `#`（如 `# 2.6 基和秩`），节用 `##`（如 `## 2.6.1 ...`）。
